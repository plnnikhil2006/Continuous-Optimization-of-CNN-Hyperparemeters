# CNN Hyperparameter Optimization using Metaheuristics

## Project Overview
This repository contains the code, report, and summary for the Optimization Techniques assignment, specifically addressing Problem A: Continuous Optimization. The project optimizes the continuous hyperparameters (Learning Rate and Dropout Rate) of a Convolutional Neural Network (CNN). 

Two gradient-free metaheuristic methods are implemented and compared:
1. Particle Swarm Optimization (PSO)
2. Genetic Algorithm (GA) 

## Repository Structure
* main.py: The well-commented Python source code used to train the models and generate the optimization results.
* OT_Project.ipynb: The project notebook file.
* report.tex: The formal LaTeX report detailing the mathematical formulation, algorithm implementation, and convergence discussion.
* summary.md: A high-level overview of the optimization results and optimal parameters found.
* optimization_results.png: The convergence plot generated by the code (to be added upon execution).

## Requirements and Setup
To run the optimization script, ensure you have a Python environment with GPU support enabled. The following libraries are required:
* torch
* torchvision
* numpy
* matplotlib
* seaborn

You can install the dependencies using:
pip install torch torchvision numpy matplotlib seaborn

## Execution
Run the optimization script directly from your terminal:
python main.py

The script will output the optimal parameters to the console and save a convergence plot as "optimization_results.png" in the current directory.
